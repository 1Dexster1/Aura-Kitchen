# 🍳 Aura Kitchen (مطبخ أورا)

A stylish, fast-paced multiplayer and solo cooking simulation game built for Web (WebGL) and Mobile (Android APK).

---

## 🌟 Key Highlights

- **Dynamic Customer Dining System (الزباين):**
  - Walk-in customers take seats at 4 dining tables in front of the open kitchen.
  - Floating order thought-bubbles with real-time patience countdowns (Green -> Yellow -> Red).
  - Eating animations, floating coin tips (`+$25`), and customer satisfaction review scores (1 to 5 Stars).
- **Multiplayer & Solo Modes (1 to 4 Players):**
  - **Solo Shift (Offline):** Switch seamlessly between 2 chefs using `Tab` (or mobile button), with an intelligent autonomous Sous-Chef Assistant.
  - **4-Player Co-op (Online & Local):** 4 distinct chefs with glowing aura rings (Ruby Red, Sapphire Blue, Emerald Green, Amber Gold).
- **Expanded 4-Player Kitchen Environment:**
  - 3 Cutting stations, 3 Stoves, dual plate dispensers, organized ingredient crates, 4 dining tables with candles, warm pendant lights, and a glowing neon "AURA KITCHEN" sign.
- **Glassmorphic Aura UI/UX & Touch Controls:**
  - Animated order queue tickets, live tip counter, shift timer, combo multiplier gauge (`x4 MAX AURA 🔥`), and shift end report.
  - Built-in Virtual Touch Joystick & Action Buttons for Android and mobile web touchscreens.
- **Cloud CI/CD Pipeline (GitHub Actions):**
  - Built completely in the cloud with GameCI: exports a live WebGL website (GitHub Pages) and an installable Android APK without straining low-spec local hardware.

---

## 🕹️ Quick Play (No Unity Engine Required!)

Double-click `index.html` (or `web/index.html`) in any web browser to play the full 3D Aura Kitchen game immediately at 60 FPS on any computer or mobile device!
