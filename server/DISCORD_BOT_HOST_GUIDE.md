# 🤖 دليل تشغيل الباك إند على استضافات بوتات الديسكورد (Discord Bot Hosting)

تم ضبط الباك إند بالكامل ليعمل بأعلى كفاءة على **أي استضافة بوتات ديسكورد** (مثل: Pterodactyl Panels, Discloud, BotGhost, PebbleHost, BisectHosting, وغيرها) دون أي تعقيد وبدون أي متطلبات خاصة.

---

## 🌟 لماذا هذا الباك إند مثالي لاستضافات البوتات؟

1. **استهلاك رام شبه معدوم (Ultra Low Memory):**
   - يستهلك السيرفر حوالي **18 ميجابايت إلى 30 ميجابايت فقط** من الـ RAM!
   - يناسب تماماً خطط البوتات المجانية والمدفوعة الضعيفة (256MB أو 512MB RAM).
2. **بدون مكتبات مجمعة (Zero Native Compilation):**
   - تم استخدام إعدادات لا تتطلب `node-gyp` أو `python` أو مفاتيح SSH التي تسبب أخطاء على حاويات البوتات.
3. **قراءة المنفذ التلقائية (`process.env.PORT`):**
   - يقرأ السيرفر المنفذ المخصص له تلقائياً من لوحة التحكم، ويعمل مباشرة.
4. **لوحة تحكم حية مدمجة (Colyseus Live Monitor):**
   - يمكنك فتح الرابط `http://YOUR-HOST:PORT/colyseus` لترى الغرف النشطة وعدد اللاعبين واستهلاك الرام والمعالج لحظياً!

---

## 📁 الملفات المطلوبة رفعها إلى الاستضافة

قم بضغط ورفع محتويات المجلد `server/` إلى مجلد البوت الخاص بك:
```text
├── index.js              <-- ملف التشغيل الرئيسي المعتمد للوحات البوتات
├── server.js             <-- الخادم وربط Colyseus مع Express
├── KitchenRoom.js        <-- منطق الغرف والـ 4 طهاة
├── KitchenState.js       <-- كائنات الـ Schema ومزامنة الحالة
├── leaderboard.json      <-- حفظ أعلى النتائج
└── package.json          <-- حزم المشروع والتبعيات
```

---

## ⚙️ إعدادات لوحة التحكم (Panel Settings):

- **Main File / Start Script**: `index.js` (أو `server.js`)
- **Node.js Version**: `Node 18` أو `Node 20` أو `Node 22` أو `Node 24`
- **Start Command**: `npm start` أو `node index.js`

---

## 🎮 ربط اللعبة بالسيرفر الخاص بك

بمجرد تشغيل السيرفر وحصولك على رابط الهوست (مثلاً `my-kitchen.discloud.app` أو `123.45.67.89:2567`):
- في ملف `index.html` (أو في اللعبة): يتصل العميل تلقائياً بنفس الدومين، أو يمكنك تعيين الرابط في السطر الخاص بـ:
  ```javascript
  const host = 'my-kitchen.discloud.app';
  ```
- في اليونيتي: ضع الرابط في مكوّن `AuraWebSocketClient` داخل `serverUrl`.
